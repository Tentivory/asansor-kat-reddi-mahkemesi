# Asansör Kat Reddi Mahkemesi

Bu depo bir yazılım projesi değildir. Bu depo, binanın dikey adalet sistemidir.

Asansör düğmesine basmak bir taleptir. Talep, duruşmasız kabul edilmez. Üçüncü kat şüpheli bulunabilir. Zemin kat torpil kokabilir. Bodrum, dosyası eksik diye reddedilebilir. Kod çalışır. Adalet çalışmaz. İkisi de bilerek böyledir.

## Neden var

Çünkü birisi dördüncü kata çıkmak istedi ve evren “hemen değil” dedi. Bu yazılım o “hemen değil” cümlesini protokole çevirir. MIT yok. ÇAY var. ÇAY, Çay Altında Yargılama lisansıdır: kodu çalabilirsin ama çayı bırakmak zorundasın.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Asansör de yoktur. Sadece hüküm vardır.

```bash
python asansor.py
python asansor.py --kat 7 --gerekce "annem bekliyor" --acele evet
python asansor.py --kat 0 --gerekce "market poşeti ağır" --acele hayir
python asansor.py --kat 13 --gerekce "uğursuz değilim" --acele belki
```

## Mahkeme heyeti

- Başkan: yanıp sönen kat lambası
- Üye: kapanmayan kapı sensörü
- Katip: “kapılar kapanıyor” diyen ama kapanmayan hoparlör
- Copilot: duruşmaya çağrıldı, gelmedi, mazereti `docs/copilot-cagri.md` içinde
